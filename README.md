# Cats at Sunset

Two cats watching the sun set and the moon rise. Click a cat to give it a heart.

**Live:** https://cats-at-sunset.vercel.app

I made this in Processing (`processing/challenge_5_Updated.pde`) and ported it to p5.js (`sketch.js`) so it runs in the browser.

Fonts: Monsieur La Doulaise and Moirai One, both under the SIL Open Font License.
